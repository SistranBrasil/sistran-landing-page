## Descrição original

## Origem

Spec: `docs/efeitos-scroll-terminal-industries.md` (atualizado 09/09). Aplicar a **linguagem de movimento** na **home** — não copiar textos, logos nem mídia da Terminal Industries.

Esta issue é a **base**. As issues dos efeitos 1–4 dependem destes tokens e de uma primitiva de revelação única, para não nascerem quatro stacks de motion.

## O que fazer

### 1. Tokens (cores da Sistran, não da referência)

Declarar em CSS (ex. `src/app/globals.css` ou `styles/motion.css` se a casa preferir arquivo novo) os tokens do doc, **trocando** as cores de marca:

| Token do doc | Valor de referência | Valor neste projeto |
| -- | -- | -- |
| `--motion-ease-out` | `cubic-bezier(.19, 1, .22, 1)` | pode alinhar a `easeExpo` já em `src/lib/motion.ts` `[0.22, 1, 0.36, 1]` — **um** easing, não dois |
| `--motion-fast/base/slow` | 300 / 500 / 1000 ms | manter |
| `--motion-logo` | 2400 ms | manter (Efeito 1) |
| `--motion-stagger-logo` | 100 ms | manter |
| `--motion-stagger-word/char` | 55 / 14 ms | manter |
| `--motion-distance-sm/md` | 24 / 48 px | manter |
| `--motion-signal` | `#abff02` (Terminal) | **ciano da marca** — `#0ed8f6` (ou token já existente) |
| `--motion-ink` | `#052424` | navy/ink da casa (`text-ink` / `#0a1f44` — escolher um e documentar) |
| `--motion-muted` | `#dddddd` | cinza claro que passe  contraste de “ainda não ativo” sobre o fundo onde for usado |

Não introduzir verde-limão da Terminal.

### 2. Primativa `Reveal` (cliente)

O doc propõe `components/motion/Reveal.tsx` + presets `fade-up` / `fade` / `scale-soft` / `line-up`. Neste repo:

* Já existem `vFadeUp`, `vTitle`, `vGrid`… em `src/lib/motion.ts` e `SectionReveal` — **não** instalar `framer-motion` (ver <issue id="decf9965-93e6-449d-a564-b923951b7af2" href="https://linear.app/sistran-labs/issue/SIS-71/efeitos-auditar-e-padronizar-as-cinco-animacoes-pedidas-ja-existem">SIS-71</issue>).
* Preferir **estender** o que existe (`motion/react` + `useReducedMotion` de `@/lib/motion`) a criar uma segunda família paralela.
* Se nascer `Reveal` / `data-reveal`, tem de ser a **única** API declarativa da home; presets batem com a tabela do Efeito 4 do doc.
* GSAP+ScrollTrigger só onde scrub/stagger de scroll exigir (BrandGrid, narrativa); limpar com `gsap.context` no unmount.

### 3. Reduced motion + dois interruptores

Espelhar o bloco do doc **e** a regra da casa (`html[data-motion="reduce"]` + `prefers-reduced-motion`) — o mesmo defeito da <issue id="65c08e51-68d7-4bf3-aa9f-19f55c94058e" href="https://linear.app/sistran-labs/issue/SIS-159/parceiros-trocar-a-grade-bento-de-16-cards-pela-trilha-horizontal">SIS-159</issue>/<issue id="38b37c99-5cd9-46a7-a1f2-47fa93d2876b" href="https://linear.app/sistran-labs/issue/SIS-183/movimento-auditar-o-espelho-prefers-reduced-motion-htmldata">SIS-183</issue>. Com reduce: tudo visível, sem scrub, sem sticky longo novo, sem split por caractere.

### 4. Escopo

Só **fundação** e fiação mínima. Não animar BrandGrid, títulos nem Soluções nesta issue — isso é das irmãs.

## SIS-193 — base de movimento entregue

**Portões**
- `npx tsc --noEmit` → limpo
- `npm run lint` → **24 problemas, 0 erros** (a linha de base da casa; ver ressalva abaixo)
- `npx next build` → verde, todas as rotas geradas
- `npm run test:copy` → OK (1193 textos distintos, nada mudou)
- Sonda de navegador `scripts/medir-efeitos-rolagem-home.mjs` (`next start`, 1440/1024/390 × 3 regimes) → tabela no comentário da SIS-195

**O que foi feito**
- `src/app/globals.css`: bloco de tokens `--motion-reveal-*`, `--motion-stagger-*`, `--motion-distance-*`, `--motion-signal/ink/muted` no `:root`, e o bloco de estados "SIS-193 · fundação dos efeitos de rolagem" no fim do arquivo.
- `src/components/motion/useRevealTrigger.ts` — o gatilho único (IntersectionObserver; escreve `data-in` no DOM).
- `src/components/motion/RevealScope.tsx` — envelope cliente para seções que são server components.

**Dois desvios do doc, declarados**
1. **Durações renomeadas.** `--motion-fast/base/slow` já existem **duas vezes** no `globals.css` (180/`var(--dur-base)`/900ms e 180/420/650ms), consumidos por outros componentes. Sobrescrever com os 300/500/1000 do doc mudaria movimento alheio em silêncio. Os novos valores entraram como `--motion-reveal-fast/base/slow`.
2. **Cores.** O lime e o `#dddddd` do Terminal foram trocados pelo sinal da marca (`--color-sky`) e por um cinza com contraste (`#5a6b80`), com a tinta em `#041b3d`.

**Mecanismo: estado em CSS, não timeline em JS.** O JS só marca `data-in`; quem anula movimento é o CSS, nas **duas** chaves (`@media (prefers-reduced-motion: reduce)` e `html[data-motion="reduce"]`). Consequências desejadas: sem quadro de movimento antes do hook convergir, sem divergência de hidratação, e conteúdo visível **sem JavaScript** (o estado escondido exige `[data-in="false"]` num ancestral, que só existe depois de montar). `pin` não é usado.

**Ressalva de tesouro alheio:** a regeneração de `copy-lock.json` absorveu trabalho não comitado de outro agente na mesma árvore (remoções em `HeroCinematic.tsx` e renumeração em `Metrics.tsx`). Mesma ressalva da SIS-192.
