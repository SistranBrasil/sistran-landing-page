## Descrição

## Pedido

Na seção **SOCIAL** de `/esg`, o foguete que acompanha o scroll (`FogueteScroll`) deve **substituir o desenho atual** (SVG interno) pelo arquivo `public/images/esg/foguete.png`.

Manter o comportamento de scroll (trajeto, sticky/progresso, reduced-motion).

## Estado atual (auditado)

* Componente: `src/components/ui/FogueteScroll.tsx` — ainda renderiza **SVG** com gradientes (entrega <issue id="ad191d64-376b-4965-927f-7606a4aff77e" href="https://linear.app/sistran-labs/issue/SIS-234/esg-social-foguete-do-scroll-colorido-e-3d-logo-gerando-talentos">SIS-234</issue> / silhueta colorida), não o PNG.
* Montado em `src/app/esg/page.tsx` (`<FogueteScroll />` na seção SOCIAL).
* Arte nova no repo: `public/images/esg/foguete.png` (~1,7 MB, fundo transparente, foguete 3D vertical com boosters azuis, nariz laranja, chamas).
* <issue id="ad191d64-376b-4965-927f-7606a4aff77e" href="https://linear.app/sistran-labs/issue/SIS-234/esg-social-foguete-do-scroll-colorido-e-3d-logo-gerando-talentos">SIS-234</issue> (In Review + `conferir`) pediu recolorir o SVG a partir do logo Gerando Talentos — esta issue **troca a fonte visual** para o raster fornecido pela usuária.

## O que fazer

1. Em `FogueteScroll`, trocar o SVG por `<Image>` / `<img>` apontando para `/images/esg/foguete.png` (preferir `next/image` se o projeto já usa no padrão; respeitar `unoptimized` se configurado).
2. Preservar wrapper de scroll (`useScroll` / `useTransform`), `aria-hidden`, `pointer-events-none`, `z-index` atrás do texto, opacidade mobile se ainda necessária para contraste.
3. Ajustar tamanho/aspecto para o PNG não estourar a seção nem cobrir ilegível o texto; medir contraste AA do texto SOCIAL no pior ponto do trajeto (390 / 1024 / 1440). Se o PNG opaco atrapalhar, atenuar opacity/`mix-blend` — **não** voltar ao SVG antigo.
4. Otimização: se 1,7 MB for pesado demais no scroll, converter/exportar WebP leve em `public/images/esg/` e servir o WebP (manter o PNG como fonte se útil).
5. Reduce: foguete parado e visível no meio do trajeto.
6. Capturas; lint OK.

## Fora de escopo

* Trocar o selo estático Gerando Talentos.
* Mudar fotos/cards SOCIAL.
* Sair da seção SOCIAL (ENVIRONMENT / GOVERNANCE).
