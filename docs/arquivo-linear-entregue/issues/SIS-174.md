Se algum desses voltar à rota, o piso volta a valer para ele — e aí é issue nova, não retomada desta.

`globals.css:3090` **é label de formulário, não label decorativo.** O piso de 11px foi concedido para label caixa-alta com tracking porque ali a caixa-alta e o espaçamento compensam o tamanho. Label de campo de formulário é texto que a pessoa precisa ler para preencher certo: vai para 12px mesmo sendo caixa-alta.

`globals.css:14114` **e** `globals.css:5214` **são** `<button>`**.** Subir a fonte muda a altura do alvo de toque. Conferir que o botão não cresce o suficiente para quebrar a linha de filtros do navegador de eventos.

**O tracking negativo dos títulos não entra aqui.** `globals.css` tem `-0.04em` e `-0.12em` calibrados para as métricas da fonte atual. Esta issue não toca em título nenhum, e não deve.

**Não converter** `px` **para** `rem` **nem o contrário.** Onde está `9px`, sobe para `11px`; onde está `0.6rem`, sobe para `0.6875rem`. Unificar unidade é refatoração de outra natureza e some no meio deste diff.
