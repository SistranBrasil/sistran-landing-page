## Pedido

Na seção **Implementações → Linha do tempo** de `/parceiros-e-implementacoes`, o **marcador que percorre a trilha** (`.roadmap-traveler` — o círculo que passa pelos cards) deve exibir **exatamente a mesma logo** usada em `/transformacao-legado`.

Referência visual: captura anexa (círculo navy, anel ciano com glow, símbolo Luminna cabeça/rede neural + estrelas).

## Estado atual (auditado)

| Rota | Montagem |
| -- | -- |
| `/transformacao-legado` | `<RoadmapTrail />` — default `traveler = "/imagens/luminna-latam.png"` |
| `/parceiros-e-implementacoes` | `<RoadmapTrail … traveler={null} />` em `page.tsx` (~L177) |

Com `traveler={null}`, o círculo CSS (borda `--signal`, drop-shadow ciano) fica **vazio** — sem o `<img>` do símbolo. A arte e o CSS do viajante já existem em `RoadmapTrail.tsx` + `.roadmap-traveler` em `legacy.css`; o asset é `public/imagens/luminna-latam.png`.

Isso foi **deliberado na** <issue id="3316d81c-10e2-40da-be3f-cdca13660613" href="https://linear.app/sistran-labs/issue/SIS-202/parceiros-e-implementacoes-etapas-layout-roadmaptrail-textos-da">SIS-202</issue> (“o símbolo da Luminna é do legado”). A usuária **revoga** essa restrição para o viajante: a marca que anda na trilha deve ser **igual** à do legado. Continua proibido colar *copy* Luminna nos cards (textos seguem `partnersTrailStops` / `TIMELINE_EVENTS`).
